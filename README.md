# Daily Deep Thinking Skill

**v2.0.0 · 从每日聊天升级为有积累的思维训练。**

先进入具体身份和现实约束，再检验直觉、机制、证据与边界。每次默认 **至少 10 轮有效互动，通常 10–14 轮**，每轮只推进一个关键问题；用户随时可暂停或提前总结。

这不是知识推送，也不是 AI 预设答案的审问。目标是让用户在新情境中独立判断，不是让用户同意 AI。

## 开始使用

将 [SKILL.md](SKILL.md) 作为训练说明提供给你的 AI 对话环境。完整项目还应能读取下面的路线、教练手册和记录模板；只提供 SKILL.md 时，附属文件不能假定自动可见。

可以直接说：

> 开始今天的深度思考。

系统应先检查可用的未完记录；有记录就续接，没有则给 3–5 个现实候选，默认 3 个。开场会说明本次训练什么，以及它与现实判断的关系。已有明确选题时直接进入讨论。

其他触发语：“继续上次讨论”“我不懂，先解释一下”“给我最强的反方”“核验这条证据”“暂停并记录当前分歧”“检查我的阶段进步”。

没有固定时间、无需补打卡。此仓库是规则与模板，不包含自动提醒服务，也不会仅因仓库更新就证明设备上的安装副本已同步。

## 六阶段、30 次主训练

| 主训练 | 能力目标 | 现实用途 |
| --- | --- | --- |
| 1–5 | 机制思维 | 从结论走向可检验的因果链 |
| 6–10 | 二阶影响 | 判断行动之后的反应、反馈与延迟 |
| 11–15 | 概率与证据 | 检查基准率、样本、因果和信心 |
| 16–20 | 利益与博弈 | 比较参与者的激励与相互反应 |
| 21–25 | 认知自检 | 检查自己的证据选择和判断标准 |
| 26–30 | 综合决策 | 在约束与不确定性下形成可调整规则 |

详见 [CURRICULUM.md](CURRICULUM.md)。30 次是训练设计，不是效果保证；按已完成的讨论而非日历推进。升级时保留可核验历史，不把训练归零。

## 这次优化了什么

- **选题：**优先有真实机制基础的反直觉问题；避免默认职场伦理、家庭两难和抽象政策开场。构造数字明确标注，真实结论先核验。
- **对话：**直接指出具体推理缺口，但用户正确时承认；不懂时教学，不机械凑轮数，也不提前揭晓整套答案。
- **证据：**区分事实、原文、作者观点和 AI 推论；核验失败如实留空，不编造引文或页码。
- **积累：**每次留下原始判断、被挑战假设、新变量、最强证据、反转条件和迁移场景。
- **评估：**区分“未观察、提示后完成、独立完成、跨场景复现”，不以聊天长度或顺从 AI 评分。
- **连续性与隐私：**可依据可靠记录续接；公开仓库只存通用材料，真实记录仅写获授权的私有位置。

## 维护与校验

```bash
python scripts/validate_project.py
```

命令检查入口、版本、30 个单元、题库、验收条目和相对链接。它不评测对话表现或长期教育效果；行为测试需另按验收清单实际运行。

保存能力和读取历史的能力取决于实际使用环境。没有持久存储时，AI 应在聊天中提供可复制记录，不声称已保存或可自动恢复。
