# Thinking Profile Schema

仅在环境提供持久化档案或用户明确要求保存时使用。记录应简短、带日期、可修订。

```markdown
# Thinking profile

## 显式偏好
- [日期] 用户明确表达的节奏、领域、格式或证据偏好。

## 训练记录
- [日期] 主题 — 起始判断；重要修正；触发修正的证据或推理；未解决问题。

## 方法信号
- [日期] 用户明确认为有帮助或无帮助的问题类型、解释方式或证据格式。

## 暂时模式
- [日期] 暂时推断及其观察依据；标注低/中置信度，被后续证据反驳时删除。

## 重访队列
- 问题 — 以后值得重访的原因；最后讨论日期。
```

规则：

- 显式陈述与推断分开保存。
- 未选择的候选菜单不写入训练记录。
- 每次完整训练最多保存一条精简记录，不保存逐字稿。
- 不记录敏感诊断、身份猜测或不必要的个人信息。
- 优先更新已有条目，不累积近义重复项。
- 暂时模式与后续表现冲突时立即修订或删除。
- 档案只用于改善选题与辅导方式，不能用于操纵用户或把用户固化成某一类型。
