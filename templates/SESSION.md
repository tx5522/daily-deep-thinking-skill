# 单次讨论记录（空白模板）

实际记录只保存到用户授权的私有位置；本文件保持空白。未知项写 `null` 或“待确认”，不要推测填满。

`status`：`in_progress` / `paused` / `ended_early` / `completed`。
`evidence_status`：`verified` / `partial` / `unavailable`；模板尚未使用时保留 `null`。
`completed_rounds` 只计用户已回应的有效互动；不计选题、工具调用或 AI 单方面输出。

## 开场定位

- 日期与时区（实际已知时）：
- 题目、身份、场景与约束：
- 本次练什么 / 为什么值得练 / 可迁移用途：
- 场景类型：真实案例 / AI 构造案例 / 混合且分别标注：

1. 原始判断与理由（真实引文或明确标注的转述）：

3. 新增并排序的关键变量：
4. 最强证据、来源及限制：
5. 结论反转条件：
6. 新场景中的迁移表现：

## 用户重写的模型

- 用户表达（没有作答时写“未完成”，不要由 AI 代填为用户答案）：

- 尚未解决的问题与证据缺口：
